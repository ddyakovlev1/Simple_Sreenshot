# Simple Screenshot

Маленькое фоновое приложение для скриншотов в Windows 10/11. Живёт только в трее и запускается вместе с системой.

## Как пользоваться

| Действие | Что происходит |
|---|---|
| **PrtSc** | Экран замирает и темнеет — режим выбора области |
| Тянуть **ЛКМ** | Рисуется рамка, рядом её размер в пикселях |
| Отпустить **ЛКМ** | Область сохраняется на рабочий стол |
| **Shift** в режиме выбора | Снимок всего экрана (монитора под курсором) |
| **Esc** или **ПКМ** | Отмена |

Файлы сохраняются как `Скриншот 2026-10-30 18-26-05.png`, при снимке звучит щелчок затвора.

Alt+PrtSc и Win+PrtSc программа не трогает — они работают как обычно в Windows.

## Трей

ПКМ по значку: «Настройки» и «Закрыть». Двойной клик по значку тоже открывает настройки.

В окне «Настройки»:

- **Запускать при запуске Windows** — автозапуск (включён по умолчанию).
- **Папка для сохранения скриншотов** — по умолчанию рабочий стол, кнопка «Обзор…» для выбора.
- **Включить звук скриншота** — щелчок затвора (включён по умолчанию).

Настройки хранятся в реестре: `HKCU\Software\SimpleScreenshot`.

## Установка

1. Открой [Releases](../../releases/tag/latest) и скачай `SimpleScreenshot.exe`.
2. Положи файл в постоянную папку, например `C:\Programs\SimpleScreenshot\`.
3. Запусти. Если Windows покажет «Система Windows защитила ваш компьютер», нажми «Подробнее» → «Выполнить в любом случае» (у exe нет цифровой подписи).

При первом запуске программа сама добавляется в автозапуск.

Если PrtSc открывает «Ножницы» вместо программы: «Параметры» → «Специальные возможности» → «Клавиатура» → выключи «Использовать кнопку Print Screen, чтобы открыть функцию создания фрагмента экрана».

## Сборка

Exe собирается автоматически в GitHub Actions при каждом изменении кода и выкладывается в релиз `latest`.

Локально: `dotnet build SimpleScreenshot.csproj -c Release`. Нужен .NET SDK; цель — .NET Framework 4.8, он встроен в Windows 10/11.
